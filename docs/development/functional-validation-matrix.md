## Current conclusion

The local-first migration has stronger automated and native Windows evidence after this pass. Native testing found a real regression in prompt external-file attachment: the old hidden file input path did not open a usable picker in Tauri. The current worktree fixes it with a native Tauri dialog plus Rust local-file context contract, and the rebuilt release executable was retested successfully. A later runtime credential fix clears stale public GitHub auth when the private GitHub credential is missing, preventing the UI from showing a connected GitHub account that cannot actually sync. Tab reordering now has HTML5, pointer and mouse test coverage; document-tree reordering now has HTML drag-data coverage plus a desktop mouse-drag fallback test. Native automated mouse input still did not prove the tab gesture in WebView2, and Codex is not moving files/folders in the user's real project as destructive evidence, so hands-on drag/drop confirmation remains open. The latest Codex-managed dev launch also failed to produce a visible native window despite Vite and the Tauri process starting, so manual launch from an interactive PowerShell is required for the next validation pass. The release must remain gated until the remaining hands-on native Windows flows, Android device pass, full native AI prompt/edit, local RAG, image generation, microphone transcription, GitHub live sync, signed release and update checks are performed with the required external credentials, devices and runtime contracts.

The handwritten-notes feature now has automated frontend and Rust coverage for contracts, storage, render/export, Markdown insertion, AI context and local RAG. It is not release-accepted on hardware yet: Windows and Android stylus pressure, palm rejection, latency, Android rotation/background recovery and packaged-device exports still require hands-on validation before publication.
