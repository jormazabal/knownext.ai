# Avance121 · Reexportar conserva el archivo privado completo

[Reporte visual](avance-121.html) · [Definición](bloque-121.md) · [Plan](plan.md).

Se corrige un defecto encontrado al revisar traslados sucesivos: el archivo privado recibido impedía crear otro archivo y un paquete documental simple podía incluir sus textos mientras omitía audio/JSON/binarios. El paquete documental completo ahora excluye toda Archivo KnowNext y lo informa como exclusión. La selección explícita parcial mantiene su ámbito y límites propios. La opción privada conserva íntegramente el archivo anterior y añade copias actuales, sin perder sus payloads ni reescribir sus Markdown/knote conservados.

Payloads anteriores mantienen rutas, para conservar enlaces. Los bytes exactos de Inventario.json, Preferencias.json y LEEME.md anteriores se guardan bajo Anteriores/<SHA del índice>. Nuevos borradores/audio/bundle utilizan una generación Actual distinta; las preferencias actuales y la cabecera permanecen en la raíz para su revisión existente. El índice incluye todas las familias y metadataSnapshots con nombre/ruta/SHA/tamaño de cabeceras anteriores. Conteos agregados y número de archivos conservados se muestran en la revisión. No se activa ningún trabajo, historial, audio o borrador por importar.

Paquete knownext.project3 cuando conserva archivo anterior; se mantiene lectura1/2/3. Índice privado conocido1/2, con campos estrictos y copias de metadatos en2. Huellas de borradores originales, partes de PCM/bundle, cabeceras originales y tamaño/representación WAV se comprueban. Cada payload y cada metadato original se referencian una vez por su ámbito, con comparación portable de nombres, evitando atribuciones múltiples y amplificación por lecturas repetidas. Se mantienen128MiB/32MiB/10000 entradas, fuentes regulares y contención; enlaces, extras no portables, inventario futuro, partes alteradas o cambios de fuente no producen una entrega parcial. Fuentes/metadatos no se normalizan para hacerlos pasar.

La adaptación de referencias del documento normal se difiere hasta que todos los archivos están presentes; no toca las copias privadas conservadas. Evita avisos falsos o romper enlaces a un borrador anterior. Los metadatos originales pueden reconstruirse a partir del índice de cabeceras; no se promete recuperar los bytes del contenedor ZIP original ni sus marcas físicas de tiempo.
