# Bloque 3 · Seguridad, privacidad y control de IA

Autoridad: completar bloque3 solicitado por el usuario. Definición recuperada de las agrupaciones del5nov: credenciales, permisos de superficies, límites de formatos, eliminación/retención y matriz de autoridad. Padre P02/T06/T07/T08/T09/T16; T17 conserva campaña real aplazada sin gasto. Sin instalación/publicación, UI nativa Windows o Gradle con incidencia pendiente.

## Criterios

- Credenciales: revisión sin secretos, rotación y retirada revisadas por huella; recuperación explícita con original cifrado y verificado, restauración solo de almacenes compatibles y sin exponer claves. Fallos/futuros no se sustituyen implícitamente. Serializar cambios con autenticación.
- Privacidad: pausar nuevos envíos por proyecto, selección de categorías y antigüedad, revisión exacta de datos locales antes de eliminar, alcance/exclusiones explícitos. No borrar documentos, audio original, historial, recibos contables ni copias privadas ajenas. Una operación interrumpida se consulta sin reenvío; contenido desconocido se conserva. No prometer borrar proveedores ni borrado forense.
- Evitar que una tarea activa republique datos durante la eliminación. Control compartido en Rust para texto, imágenes, investigación, dictado y grabación; capturar/guardar sin envío siguen disponibles. No alterar presupuestos ni ejecutar IA para comprobar.
- Inventario de superficies y matriz de autoridad: las capacidades no heredan permisos del contenido. Contrastar solo lectura, proyecto/base/permiso cambiado, resultados falsificados y rutas adversas. Navegación y enlaces no abren protocolos arbitrarios. Mantener PDF/Mermaid/imágenes/audio locales.
- Límites comunes previos a decodificar adjuntos y extracción de contexto; formatos/archivos desconocidos no se normalizan como vacíos. Corpus adverso dirigido y reutilización de resultados no afectados.
- UX integrada, consulta bajo demanda, confirmación visible, estados parciales/obsoletos y acuse incierto; desktop y320px. Documentación/backlog/reporte visual. P10 conserva aceptación instalada, corpus representativo y regresión final.
