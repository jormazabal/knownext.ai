Son límites de entradas/lectura, no una garantía de tiempo de los procesos Git ni de memoria total del runtime. Los árboles completos pueden contener entradas internas idénticas; solo las rutas distintas se ofrecen, validan y resuelven conforme a la política de proyecto. Revisión actual, catálogo y selección se revalidan antes de publicar. Cambiar ubicación, conexión, remoto, base local o formato no se interpreta como permiso para adoptar otra fuente.
