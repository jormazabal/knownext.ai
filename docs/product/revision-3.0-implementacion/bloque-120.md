# Bloque120 · Inventario de ubicaciones conservadas y proyectos retirados

F04/F17/T08. Completar el inventario de almacenes conocidos de proyectos incluyendo fichas retiradas y ubicaciones conservadas en su catálogo, sin restaurar proyecto, reclamar propietario ni leer payloads. Distinguir proyecto retirado de ubicación conservada de un proyecto aún registrado. Deduplicar ubicaciones coincidentes/anidadas; identidades de fila ligadas también a ubicación. El catálogo retirado futuro/no accesible produce cobertura parcial y se conserva.

El presupuesto opcional cuenta estas copias; retirar el proyecto no debe hacer desaparecer sus bytes observados ni liberar cuota ficticia. Si una ubicación no está disponible, no afirmar medición completa. No se concede autoridad de restauración/borrado a partir de metadatos. Verificar retirada real y catálogo futuro, interfaz/SDK y dos estados visuales; sin suites completas, gasto IA o instalación.
