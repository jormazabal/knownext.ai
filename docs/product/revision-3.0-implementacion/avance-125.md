Conserva objetos y referencias anunciadas bajo nombres internos; el archivo original mantiene también sus nombres y metadatos originales. Índice preparado desde el punto elegido sin checkout. La gestión asistida de una preparación interrumpida sigue pendiente; su fuente portable permanece.

Adopción del historial activo conserva sus reglas de trabajo, sin anunciar que .git esté cubierto por el presupuesto opcional de recuperación. Se permite que desaparezcan temporales propios de Git mientras ejecuta y se mide estrictamente el repositorio estable antes de publicar. Git para Windows recibe la ubicación mediante -C y el nombre relativo del repositorio, evitando el fallo de --git-dir con rutas canónicas verbatim. La publicación conserva las rutas nativas completas.
