# Avance 17 · Plantillas que se pueden trasladar

**Primera entrega de F03 implementada y contrastada localmente:** guardar y reutilizar plantillas con variables/vista previa, exportar una plantilla revisada e importarla sin sustituir el catálogo. Continúan assets, proyectos completos y distribución de catálogos múltiples. Diez paquetes iniciados, ninguno cerrado por completo. VERSION 2.6.0.

## Resultado

- Archivo `knownext.document-template`, versión 1: formato, versión, nombre, descripción y Markdown. No incorpora identidad privada, fecha de origen, raíz, ajustes, credenciales ni valores usados para rellenar otros documentos. La revisión muestra estructura visual y archivo completo; advierte de información personal escrita dentro del texto. No es un detector automático de secretos.
- Inspección Rust estricta: versión futura, campos extra, recursos locales, datos inválidos o más de 2 MiB producen error conservando el original. La confirmación vincula bytes revisados y SHA; se importa con identidad local nueva y nombre explícito.
- Colisión: exige otro nombre, conserva archivo/formulario y ambas plantillas. Al editar el nombre desaparece el aviso del intento anterior. No hay reemplazo silencioso.
- Windows: diálogo y lectura regular/acotada en Rust, destino JSON nuevo y creación exclusiva. Estado privado y rutas protegidas no son destinos válidos. Android: ACTION_OPEN_DOCUMENT y lectura ContentResolver fuera del hilo UI, límite sobre bytes reales y UTF-8 estricto. No se confía en MIME/tamaño declarados por el proveedor.
- Exportación de una revisión fija, temporal privado y entrega nativa existente. Acuse tras escritura/cierre con nombre del proveedor. Cancelar no comunica guardado; el temporal se retira al terminar. En navegador solo se anuncia descarga solicitada.
- Subdiálogo compacto desde Crear documento: una superficie visual de revisión, acciones siempre fuera del scroll y 44 px. Cancelar conserva el nombre/campos del documento en preparación y devuelve el foco. Teclado Android mantiene acciones visibles.

## Continúa

Selección/guardado físicos Windows, otros proveedores de documentos Android, TalkBack, rotación y versiones de WebView necesitan contraste propio. Un fallo de escritura del proveedor Android puede dejar un archivo parcial y se informa de revisarlo. Windows exige un nombre nuevo aunque el selector permita confirmar sustitución. No se declara transferencia completa de proyectos ni portabilidad de assets con este archivo.

Siguiente corte: conservar las propuestas IA manuales desde su recepción, con cuotas reales del almacén y recuperación como copia revisable; no ejecutar posiciones antiguas tras reiniciar. Continúa el [plan completo](plan.md), sin commit, integración, publicación ni aceptación humana de 3.0.
