### Publicación de restauración revalidada
El servicio restore_version recibe las bases originales del cuerpo y captura la ruta antes de consultar el contenido Git. Inmediatamente antes de guardar vuelve a resolver ruta, comprobar base de archivo y revisión privada, sin adoptar una posterior. Un cambio detectado conserva archivo/borrador e informa que no se restauró. El caso nuevo prueba directamente el límite de publicación del servicio con base de disco o borrador obsoletos: conserva ambos y no registra otra versión; con bases actuales ejecuta la ruta completa del runtime y crea una tercera versión, manteniendo legible la histórica. No inyecta una edición en un instante exacto dentro del proceso Git ni acredita CAS frente a una sustitución externa posterior a la última comprobación. Actualización de alcance del mismo bloque98, sin crear otro paquete o cierre general.
