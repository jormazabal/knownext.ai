# KnowNext.ai 2.0.1

KnowNext.ai 2.0.1 is a local-first quality release focused on GitHub access degradation, production runtime copy, and settings cleanup.

## What Changed

- GitHub-backed projects now keep local editing and local history available when GitHub is disconnected, unauthenticated, offline, or inaccessible.
- Automatic GitHub remote sync pauses while access is unavailable and can recover after the user reconnects or regains permission.
- Open documents show a quiet footer status such as `Sin acceso a GitHub` instead of repeatedly prompting save/sync actions when the remote cannot be used.
- Markdown session dirty-state comparison now normalizes line endings and final newlines so opening a document does not immediately create false pending changes.
- The settings modal now reflects the local Rust/Tauri runtime only: health, version, profile, diagnostics, app data, and updater state. Obsolete backend port, restart, external executable, and auxiliary service controls were removed.
- Installed production builds no longer show development/mock GitHub login text when remote GitHub OAuth is unavailable.
- The Windows manual download uses the MSI installer because the unsigned NSIS executable can be blocked by Windows security policy after browser download. The NSIS executable remains attached as a secondary asset.

## Validation Required Before Publication

- `pnpm version:check`
- `pnpm release:check`
- Windows Tauri release build with updater signing configured
- Android release build with Android signing configured
- Manual Windows and Android acceptance from `docs/development/manual-test-checklist.md`
- GitHub release asset verification for MSI, NSIS, Windows signatures, `latest.json`, Android APK, and `android-latest.json`

## Known Limitations

- Real GitHub remote synchronization remains replaceable/mock-backed until Rust GitHub credentials, permissions, conflict handling, and recovery flows are validated end to end.
- AI provider execution remains replaceable/mock-backed until provider credentials, privacy rules, and runtime routing are validated end to end.
- Document previews and exports are Rust-managed and currently best-effort for formats that require complex conversion.

Do not publish this release if packaged Windows or Android builds fail, updater signing is unavailable, Android signing is unavailable, critical manual acceptance fails, or update manifests do not resolve to `2.0.1`.
