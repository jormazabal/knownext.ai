# KnowNext.ai 2.4.0

KnowNext.ai 2.4.0 is a save, synchronization and export fidelity release focused on making project state visible per file and making exported documents closer to the edited Markdown document.

## What Changed

- `Guardado y sincronización` replaces the previous protection/history drawer with a single file list ordered by modification date.
- Each file now carries structured Local, Historial local and GitHub states so users can see drafts, pending local history, pending remote work, conflicts, omitted files and paused GitHub access in one place.
- The drawer includes phase filters, per-file actions, batch local-history actions, draft save/discard actions and GitHub push/pull entry points without exposing branch names in the product UI.
- The Rust runtime now exposes a file-sync overview contract and keeps Git/filesystem inspection inside local services.
- External-change handling is integrated into the file overview so safe Markdown imports and blocked private files remain reviewable without scattering state across tabs.
- DOCX and PDF exports now understand more Markdown structure: headings, paragraph spacing, inline bold/italic/code/link styling, tables, horizontal rules and embedded image assets.
- Export templates now include paragraph space-before, per-heading spacing and Mermaid diagram raster resolution controls.
- Exported image handling now resolves Markdown, HTML and data-URL image references and supports desktop JPEG, GIF and WebP rendering paths.
- AI provider usage records are persisted by the Rust runtime and summarized by month, capability, model, source and estimated cost.

## Validation Required Before Publication

- `pnpm version:check`
- `pnpm release:check`
- Windows Tauri release build with updater signing configured
- Android release build with Android signing configured
- Manual Windows acceptance: update from 2.3.0 to 2.4.0, open an existing project, open `Guardado y sincronización`, verify Local, Historial local and GitHub columns, save and discard an open draft, import an external Markdown file, and confirm a private `.env` file remains omitted.
- Manual export acceptance: export a document containing headings, paragraphs, links, tables, Mermaid diagrams and Markdown/HTML images to DOCX and PDF; confirm spacing, styles, diagram resolution and images render as expected.
- Manual AI usage acceptance: run a document AI request with provider credentials configured and confirm usage appears in runtime summaries.
- Manual Android smoke/update acceptance from 2.3.0 to 2.4.0, including offline operation without a workstation app or external product service running.
- GitHub release asset verification for MSI, NSIS, Windows signatures, `latest.json`, Android APK, and `android-latest.json`.

## Known Limitations

- GitHub remote synchronization still requires a valid GitHub account and repository permissions; when access is missing, remote sync remains paused while local history stays available.
- PDF export on Android still uses the lightweight fallback path for diagram/image-heavy documents until the desktop PDF renderer is made Android-compatible.
- Complex Markdown and document conversion remain best-effort where formats require advanced layout semantics beyond the local renderer.
- AI provider usage depends on provider responses exposing usage metadata; estimated costs are local approximations and should be treated as operational guidance.
- Agentic web research remains unavailable; local guided agentic limits are exposed but external web investigation is intentionally not active.

Do not publish this release if packaged Windows or Android builds fail, updater signing is unavailable, Android signing is unavailable, critical manual acceptance fails, or update manifests do not resolve to `2.4.0`.
