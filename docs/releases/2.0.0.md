# KnowNext.ai 2.0.0

KnowNext.ai 2.0.0 migrates the product to a local-first Tauri v2/Rust runtime for Windows and Android.

## What Changed

- Windows and Android now use local Tauri/Rust commands for product operations.
- The frontend API boundary remains under `apps/desktop/src/lib/api`, but it no longer calls an HTTP product server.
- The previous product server runtime path, auxiliary packaging, mobile endpoint discovery, server scripts, and server contract tests were replaced by Rust/Tauri equivalents.
- Rust crates now own shared contracts, storage/project operations, document helpers, and AI orchestration entry points.
- Android is treated as an autonomous app and must work offline without a workstation service running.

## Validation Required Before Publication

- `pnpm version:check`
- `pnpm build`
- `pnpm test`
- `pnpm rust:test`
- `pnpm bundle:check-clean`
- `pnpm release:check`
- Windows Tauri release build with updater signing configured
- Android release build with Android signing configured
- Manual Windows and Android acceptance from `docs/development/manual-test-checklist.md`
- GitHub release asset verification for NSIS, MSI, Windows signatures, `latest.json`, Android APK, and `android-latest.json`

## Known Limitations

- AI provider execution remains replaceable/mock-backed until provider credentials, privacy rules, and runtime routing are validated end to end.
- GitHub synchronization remains replaceable/mock-backed until Rust Git/GitHub sync and conflict handling are validated end to end.
- Document previews and exports are Rust-managed and currently best-effort for formats that require complex conversion.

Do not publish this release if packaged Windows or Android builds fail, updater signing is unavailable, Android signing is unavailable, critical manual acceptance fails, or update manifests do not resolve to `2.0.0`.
