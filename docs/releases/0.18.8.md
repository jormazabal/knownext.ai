# KnowNext.ai 0.18.8

## Summary

KnowNext.ai 0.18.8 adds a user-facing activity view for project protection and synchronization, and improves the first GitHub upload path for projects that already had local Git history.

## Product Changes

- `Protección e historial` now includes an `Actividad` tab with recent actions grouped by day.
- Activity entries explain what happened in editor-friendly language, without exposing branch names or Git commands.
- Pending GitHub upload is shown as a clear action to upload the local history, especially after connecting GitHub to an existing local Git project.
- The project protection summary links users to the activity view when they want confirmation of recent actions.

## Technical Notes

- Added a backend activity service backed by `activity.json`, keeping the last 100 user-facing events per project.
- Added `/api/projects/{project_id}/activity` endpoints and typed frontend API access.
- Recorded activity for local version creation, GitHub connection and verification, push/pull, automatic push, external change saves, omitted-change acceptance, and restores.
- Added safe push handling for missing or empty remote branches by pushing the current local history to the target remote branch.

## Validation

- `pnpm --filter @knownext/desktop build`
- `python -m pytest backend/tests/test_api.py -q`
- In-app browser validation at `http://127.0.0.1:1420/` confirmed that the protection modal opens, the `Actividad` tab is available, and the view does not expose technical Git terms.

## Distribution

The GitHub release for `v0.18.8` must include the NSIS installer, MSI installer, both updater signatures, and `latest.json`. The published `latest.json` must resolve to version `0.18.8` and keep `windows-x86_64.url` pointing to the MSI artifact.
