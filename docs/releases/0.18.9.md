# KnowNext.ai 0.18.9

## Summary

KnowNext.ai 0.18.9 fixes the GitHub conflict review flow in `Protección e historial`, replacing a dead-end button with clear conflict guidance and a real action to open the repository in GitHub.

## Product Changes

- `Ver diferencias en GitHub` no longer appears as a button that simply keeps the user on the same tab.
- The summary action is now `Revisar GitHub`, and the GitHub tab offers `Abrir repositorio en GitHub`.
- When local history and GitHub have both advanced, the app explains that automatic synchronization is blocked to avoid overwriting work.
- The GitHub tab shows the local and remote version references when available.

## Technical Notes

- Added a layout-level action for opening the active project's GitHub repository through the existing external-link runtime helper.
- The GitHub tab now renders a dedicated conflict guidance panel for project sync conflicts.
- Sync conflict objects now preserve shortened local and remote hashes when the backend detects diverged history or a rejected push.

## Validation

- `pnpm --filter @knownext/desktop build`
- `python -m pytest backend/tests/test_api.py -q`

## Distribution

The GitHub release for `v0.18.9` must include the NSIS installer, MSI installer, both updater signatures, and `latest.json`. The published `latest.json` must resolve to version `0.18.9` and keep `windows-x86_64.url` pointing to the MSI artifact.
