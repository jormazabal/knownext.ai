# KnowNext.ai 0.18.2

## Summary

KnowNext.ai 0.18.2 polishes the desktop editing workspace with clearer Markdown document typography, viewer zoom control, file-tree display preferences, and more native Windows window behavior.

## Product Changes

- Added lower paragraph spacing so real Markdown documents read with a cleaner rhythm in the visual editor.
- Reduced the `H1` scale slightly and made heading top margins proportional to each heading level.
- Added a Markdown visualizer zoom selector to the editor toolbar, shared by editable and readonly document previews.
- Added a document-tree option to show or hide file extensions while preserving the full underlying file names.
- Matched the account footer to the document footer height, white surface, top border, and compact typography.

## Desktop Behavior

- The custom title bar now supports double-click maximize and restore from the header area, while keeping the window control buttons isolated.
- Restored window state is clamped to the visible monitor work area on startup, and oversized windows are reduced when needed so the app opens fully on screen.

## Technical Notes

- Added focused frontend coverage for title-bar double-click behavior, document-tree extension visibility, Markdown zoom controls, account footer styling, and window-state clamping.
- Kept the window-state correction in the Tauri runtime integration layer rather than React presentation components.
