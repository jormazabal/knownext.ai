# KnowNext.ai 2.5.3

KnowNext.ai 2.5.3 introduces handwritten `.knote` documents and AI-assisted drawing as editable pencil strokes inside the local-first workspace.

## What Changed

- Added `.knote` handwritten note documents with project tree creation, tabbed editing sessions, dirty-state handling, save/export actions and compact pencil/eraser/grid tools.
- Added `draw_handwritten_note` as a Rust-mediated AI action for active handwritten notes, including target page context, permissions, structured SceneSpec output and draft application.
- Added the `knownext-drawing` crate for deterministic layout, stroke synthesis, pencil role mapping, handwritten text rendering support, fill/shadow strokes and visual QA.
- Added the `knownext.handwritten_drawing` base skill with drawing modes for flows, architecture, timelines, matrices, mind maps, wireframes and creative sketches.
- Improved AI-generated strokes so they render through the same smoothed pencil texture path as manual drawing, with jitter, pressure variation, sketch passes and no solid filled vector shapes.
- Added figurative drawing routes for cat/dog portraits and an infographic route for Starship-style hero drawings with handwritten callouts and internal detail strokes.
- Expanded local runtime and web development API support for handwritten note persistence, import/export and AI-updated note sessions.

## Validation Required Before Publication

- `pnpm version:check`
- `pnpm release:check`
- Windows Tauri release build with updater signing configured
- Android release build with Android signing configured
- Manual handwritten note acceptance: create a `.knote`, draw manually, save/reopen, export and verify undo/draft state.
- Manual AI drawing acceptance: ask for simple shapes, a portrait, a Starship-style infographic and page cleanup from an active `.knote`.
- Manual update acceptance on Windows and Android from the previous public version.
- GitHub release asset verification for MSI, NSIS, Windows signatures, `latest.json`, Android APK and `android-latest.json`.

## Known Limitations

- Complex freehand illustration quality is still best for structured sketches, diagrams, infographics and simple portraits. High-fidelity artistic rendering remains an iterative product area.
- AI drawing output is editable as strokes, but semantic generated element metadata is currently used mainly for diagnostics and future regeneration/editing workflows.

Do not publish this release if packaged Windows or Android builds fail, updater signing is unavailable, Android signing is unavailable, critical manual acceptance fails, or update manifests do not resolve to `2.5.3`.
