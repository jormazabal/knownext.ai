# KnowNext.ai 2.5.2

KnowNext.ai 2.5.2 improves the Markdown editing workflow with visual text highlights and fixes two interaction regressions found during local validation.

## What Changed

- Added KnowNext.ai text highlights in the Markdown editor with controlled inline `<mark data-knx-highlight="...">` persistence, five supported colors, visual toolbar controls, and MD/PDF/DOCX export support.
- Registered the same highlight rendering in editable and readonly Markdown surfaces so documents, previews and release notes stay visually consistent.
- Updated word counts to ignore controlled inline HTML tags and attributes.
- Updated AI Markdown instructions so existing highlights are preserved and generated highlights use only the supported color set.
- Fixed stale editor-controller cleanup so toolbar actions do not remain disabled after selection, deselection, tab switching or editor remounts while the document is still editable.
- Fixed document creation dialogs so Enter runs the primary action.
- Added a web development local runtime fallback for document/project operations that previously required the packaged Tauri runtime.

## Validation Required Before Publication

- `pnpm version:check`
- `pnpm release:check`
- Windows Tauri release build with updater signing configured
- Android release build with Android signing configured
- Manual editor acceptance: apply, change and remove all highlight colors, then save/reopen and export to MD, PDF and DOCX.
- Manual toolbar acceptance: switch documents, select/deselect text and confirm formatting buttons stay enabled whenever the visual editor is active.
- Manual document creation acceptance: create a document from the dialog with Enter and with the primary button.
- GitHub release asset verification for MSI, NSIS, Windows signatures, `latest.json`, Android APK and `android-latest.json`.

## Known Limitations

- GitHub synchronization still depends on account, repository permission and network availability; unavailable remotes pause automatic sync while local history remains usable.

Do not publish this release if packaged Windows or Android builds fail, updater signing is unavailable, Android signing is unavailable, critical manual acceptance fails, or update manifests do not resolve to `2.5.2`.
