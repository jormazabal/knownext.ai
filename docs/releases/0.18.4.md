# KnowNext.ai 0.18.4

## Summary

KnowNext.ai 0.18.4 improves GitHub credential recovery from project configuration with clearer user language and a direct connection test before saving.

## Product Changes

- Renamed the recovery action to `Conectar cuenta de GitHub`, matching the authorization process users actually start.
- Added `Verificar conexión` next to the account actions when GitHub rejects the current connection.
- Shows inline feedback while the app checks access, and then reports whether the connected account can access the configured repository.
- Keeps `Cerrar sesión` available for users who need to switch to another GitHub account.

## Technical Notes

- Added a backend sync endpoint to verify GitHub repository access for the configured project.
- Added GitHub API service support for validating repository metadata and permissions with the stored credentials.
- Wired the project edit modal through the existing API layer instead of performing GitHub checks from React.
- Added frontend coverage for the credential recovery controls and backend coverage for the repository verification endpoint.
