# KnowNext.ai 0.18.6

## Summary

KnowNext.ai 0.18.6 fixes the project GitHub verification flow when local Git cannot find `origin/main` after reconnecting credentials.

## Product Changes

- The project configuration no longer exposes Git's technical `ambiguous argument 'origin/main'` error when the remote branch is missing locally.
- A GitHub project with no comparable remote branch is shown as pending upload instead of a credential failure.
- Verification can now recover cleanly when GitHub uses another default branch or when the first synchronization still needs to create the remote branch.

## Technical Notes

- Remote reference resolution now checks the configured branch, current local branch, `main`, `master`, `origin/HEAD`, and fetched origin branches.
- Missing remote refs return `None` instead of raising a sync error.
- Added backend coverage for local Git repositories with a configured remote but no fetched remote branch.

## Validation

- `python -m pytest tests/test_api.py -k "git_service_missing_remote_ref_is_not_a_sync_error or git_service_uses_basic_token_auth_for_github_https"`
- `pnpm version:check`

## Distribution

The GitHub release for `v0.18.6` must include the NSIS installer, MSI installer, both updater signatures, and `latest.json`. The published `latest.json` must resolve to version `0.18.6` and keep `windows-x86_64.url` pointing to the MSI artifact.
