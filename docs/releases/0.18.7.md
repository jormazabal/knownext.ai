# KnowNext.ai 0.18.7

## Summary

KnowNext.ai 0.18.7 fixes stale technical Git messages in the project configuration modal after GitHub verification correctly identifies a project as pending upload.

## Product Changes

- `Pendiente de subir` no longer appears together with the previous `fatal: ambiguous argument 'origin/main'` Git detail.
- The GitHub configuration panel now explains pending upload, remote changes, and synchronized states in editor-friendly language.
- Users see the current synchronization state instead of an old technical error once the credential and remote checks have recovered.

## Technical Notes

- The backend clears `lastError` when scan resolves to normal pending upload or remote-available states.
- The project edit modal derives a friendly GitHub status detail when no active error exists.
- Added backend coverage for clearing stale sync errors when a local Git project has a GitHub remote but no fetched remote branch.

## Validation

- `python -m pytest tests/test_api.py -k "local_git_github_scan_clears_stale_error_when_remote_branch_is_missing or git_service_missing_remote_ref_is_not_a_sync_error"`
- `pnpm --filter @knownext/desktop test -- CreateProjectDialog`

## Distribution

The GitHub release for `v0.18.7` must include the NSIS installer, MSI installer, both updater signatures, and `latest.json`. The published `latest.json` must resolve to version `0.18.7` and keep `windows-x86_64.url` pointing to the MSI artifact.
