# KnowNext.ai 0.20.0

## Summary

This release adds a product-quality read-only reference document viewer so users can consult PDF, DOCX, and XLSX project documents inside KnowNext.ai without leaving the workspace or interrupting the Markdown editing flow.

## Product Changes

- Added read-only reference document tabs for supported project attachments:
  - PDF
  - DOCX
  - XLSX
- Keeps Markdown as the only editable document format and preserves Milkdown as the Markdown editor.
- Opens reference documents from the document tree as native workspace tabs.
- Shows document type and read-only status in the bottom status bar.
- Adds clear fallback states for unavailable previews, protected files, stale previews, oversized files, and external opening.

## PDF And DOCX Preview

- Added a PDF-based preview surface with zoom, page navigation, fit controls, search, and external-open actions.
- Converts DOCX previews through the backend when a local converter is available.
- Provides a backend-generated fallback preview for DOCX content when paginated conversion is unavailable.
- Highlights matching search text in PDF/DOCX previews when searchable text is available.

## XLSX Preview

- Added a read-only spreadsheet grid for workbook previews.
- Added a compact toolbar sheet selector with a floating options list.
- Removed the unnecessary XLSX pages mode and side panel so the workbook view stays focused on sheet inspection.
- Aligns the grid flush with the preview surface and supports selecting/copying cell values.

## Workspace Tabs

- Reworked overflowing tabs to avoid horizontal browser scrollbars.
- Added a floating vertical list of open tabs when the tab strip does not fit.
- Added adjacent-tab navigation controls so users can activate the previous or next tab directly.

## Technical Notes

- Added typed frontend preview API contracts under `apps/desktop/src/lib/api`.
- Added the `Reference Document Preview Engine` feature area in the desktop app.
- Added FastAPI preview routes, schemas, and backend services for validation, cache, PDF/DOCX/text/workbook renditions, conversion detection, and spreadsheet extraction.
- Keeps file reading, validation, conversion, extraction, and cache handling in FastAPI instead of React.
- Stores preview renditions outside the project workspace and never modifies source files.
