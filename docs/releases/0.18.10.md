# KnowNext.ai 0.18.10

## Summary

This release makes GitHub synchronization conflicts actionable from inside KnowNext.ai.

## Product Changes

- Replaced duplicated repository-opening actions with clear synchronization choices.
- Shows `Sincronizar con GitHub` when the local history needs to be uploaded and GitHub has no comparable version.
- Shows explicit conflict choices when both the local project and GitHub have advanced:
  - `Usar este equipo`
  - `Usar GitHub`
- Adds confirmation before applying either conflict resolution.

## Technical Notes

- Added a frontend API wrapper for resolving project sync conflicts.
- Added backend resolution logic for keeping the local history and pushing it to GitHub.
- Added backend resolution logic for taking the GitHub version and resetting the local repository.
- Blocks taking the GitHub version if the local working tree has unsaved changes.

## Validation

- `pnpm --filter @knownext/desktop build`
- `pnpm --filter @knownext/desktop test -- --run`
- `pytest backend/tests`
- Browser validation of the `Protección e historial` modal.
