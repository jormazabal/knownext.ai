# KnowNext.ai 3.0.0

Un espacio de trabajo local más compacto para Windows y Android, con navegación, edición, recuperación y sincronización revisadas conjuntamente. [Publicada el 7 de noviembre de 2026](https://github.com/jormazabal/knownext.ai/releases/tag/v3.0.0), con ambos canales de actualización verificados.

## Alcance

- Espacio compacto de tres paneles contextuales, navegación y acciones por lote; ajustes habituales y avanzados.
- Edición visual Milkdown, referencias y recursos, plantillas y exportaciones; historial, comparación y reversión revisadas.
- Integridad, revisión de conflictos, borradores, migración, cuotas/retención y recuperación local; copias programadas con la aplicación abierta.
- Gestión compacta de grabación, actas y notas manuscritas, con recuperación y revisión de fuentes.
- Revisión humana de evidencia de investigación y asistencia IA mediada por Rust, con límites y consentimiento visibles.
- Carga de vistas bajo demanda, diagnóstico de tiempos sólo en memoria y búsqueda Unicode con cobertura parcial explícita cuando se alcanzan límites.
- Conexión directa con Proton en beta experimental: sesión cifrada recordada, eventos, recuperación, conflictos, carpetas vacías, retención local protegida y migración con retorno, sin instalar Proton Drive.
- Corrección de pendientes falsos al consultar/abrir vistas y de nombres Git tratados como patrones en las migraciones compatibles.

## Proton experimental

Integración de terceros no respaldada oficialmente por Proton, para uso personal no comercial. El SDK aún no está preparado para aplicaciones de terceros en producción y tiene una migración criptográfica prevista; se mantienen sus [directrices oficiales](https://github.com/ProtonDriveApps/sdk/blob/05c9115955589d9f6ab7392a36f8f0cb39327133/README.md). Los documentos siguen en local. La sincronización trabaja mientras la aplicación está abierta y dispone de conexión; un fallo de red conserva el trabajo para reintentarlo.

La aplicación mantiene Android7/API24 como mínimo general. Proton requiere Android10/API29 o posterior y arquitectura de64bits. No incluye OneDrive, Google Drive ni proyectos sólo cloud. La limpieza no purga publicaciones de Proton ni elimina bases/variantes necesarias; el aviso de traslado exige revisar la conexión en cada dispositivo.

El [alcance consolidado](../product/revision-3.0-implementacion/consolidacion-140-alcance.md) conserva las50propuestas/70capacidades y sus exclusiones.

## Límites pendientes de aceptación

- La actualización 2.6→3.0 se verificó con datos sintéticos: Windows hospedado y APK ARM64 mediante traducción en emulador Android. No acredita todos los perfiles personales ni hardware físico.
- Dispositivos Windows/Android representativos, SAF/Keystore, audio, suspensión/cortes físicos, DPI/IME/lectores, lápiz y personas.
- Git nativo Android no disponible; no se promete paridad por simulación.
- Reconocimiento continuo, diarización y tiempos por palabra condicionados a fuentes/dispositivos compatibles; PDF usa texto y orden de flujo, sin OCR automático.
- Bibliotecas de5.000archivos pueden quedar parcialmente examinadas con presupuesto2s; no se establece una mejora estable de latencia del editor.
- T17 con proveedor real sigue aplazado por decisión de no gasto. No se envía documentación personal ni se hacen llamadas facturables para esta aceptación.
