# KnowNext.ai 2.5.4

KnowNext.ai 2.5.4 is a workflow correctness release focused on making new and imported project items land where the user is working.

## What Changed

- Fixed the project tree `Añadir` menu so new folders, Markdown documents, handwritten notes and imported files are created in the selected folder when a folder is selected.
- When a document or other file is active, new and imported items now land in that file's parent folder instead of the project root.
- AI-created Markdown documents and AI context sources added back into the project now carry the same target folder context through the Rust runtime.
- Updated menu descriptions from root-oriented copy to current-location copy.
- Expanded frontend, Rust and manual validation coverage for current-folder creation and import.

## Validation Required Before Publication

- `pnpm version:check`
- `pnpm release:check`
- Windows Tauri release build with updater signing configured
- Android release build with Android signing configured
- Manual create/import acceptance from a selected folder and from an active nested document.
- Manual AI document creation acceptance from a selected folder or active nested document.
- Manual update acceptance on Windows and Android from the previous public version.
- GitHub release asset verification for MSI, NSIS, Windows signatures, `latest.json`, Android APK and `android-latest.json`.

## Known Limitations

- Root remains the fallback destination when no selected folder, active document or active project file can be resolved in the current tree.

Do not publish this release if packaged Windows or Android builds fail, updater signing is unavailable, Android signing is unavailable, critical manual acceptance fails, or update manifests do not resolve to `2.5.4`.
