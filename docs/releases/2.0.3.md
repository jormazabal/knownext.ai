# KnowNext.ai 2.0.3

KnowNext.ai 2.0.3 is a local-first quality release focused on GitHub recovery, prompt context, runtime diagnostics, and release validation coverage.

## What Changed

- Stale public GitHub auth state is now cleared when the matching private credential is missing, preventing false connected-account states.
- GitHub login no longer shows an empty device-code flow when the runtime cannot start a usable GitHub OAuth device flow.
- GitHub-connected projects are normalized to local Git versioning with GitHub as a remote sync target.
- GitHub remote access failures are treated as paused product states so users can keep editing, saving, and keeping local history without repeated sync errors.
- Prompt context handling was revalidated for project-tree drag/drop, external file drag/drop, native file-picker uploads, and nested Markdown imports.
- Imported Markdown files now enter the project through the Rust-managed local import contract instead of being read directly by the React shell.
- Auxiliary document prompt and AI context-source routes now encode document-backed IDs before crossing the frontend/Rust boundary.
- The auxiliary Rust `/ai/prompt` contract preserves active document Markdown and document identity.
- Runtime logging and log-folder access routes are now backed by local Rust contracts.
- Automated coverage was expanded across settings, dialogs, tree drag/drop, tab reorder, prompt context, transcription, previews, release notes, updater UI, GitHub login states, and local runtime contracts.

## Validation Required Before Publication

- `pnpm version:check`
- `pnpm release:check`
- Windows Tauri release build with updater signing configured
- Android release build with Android signing configured
- Manual Windows update acceptance from 2.0.2 to 2.0.3
- Manual Android update acceptance from 2.0.2 to 2.0.3
- GitHub release asset verification for MSI, NSIS, Windows signatures, `latest.json`, Android APK, and `android-latest.json`

## Known Limitations

- GitHub remote synchronization requires a valid GitHub account and repository permissions; when access is missing, remote sync is paused while local history remains available.
- AI provider execution requires locally stored OpenAI credentials and still needs end-to-end validation with real keys before provider acceptance can be claimed.
- AI image generation is not an accepted 2.0.3 capability; settings show it as unavailable until local asset generation is implemented through Rust/Tauri.
- Automatic semantic RAG/vector-store and agentic web research are not accepted 2.0.3 capabilities; settings show them as unavailable while explicit prompt context remains usable.
- Document previews and exports are Rust-managed and currently best-effort for formats that require complex conversion.

Do not publish this release if packaged Windows or Android builds fail, updater signing is unavailable, Android signing is unavailable, critical manual acceptance fails, or update manifests do not resolve to `2.0.3`.
