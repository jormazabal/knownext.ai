# KnowNext.ai 0.19.0

## Summary

This release adds Markdown export workflows for users who need to deliver documents outside KnowNext.ai.

## Product Changes

- Added export actions for Markdown documents in the editor toolbar.
- Added export access from the document tree through a single `Exportar` item with a floating format submenu.
- Supports exporting Markdown documents as:
  - Markdown (`.md`)
  - PDF (`.pdf`)
  - Word (`.docx`)
- Uses the system save-as dialog when available so users can choose the destination folder and filename.
- Keeps exported content focused on the Markdown body instead of prepending the source filename.

## Export Template

- Added an `Exportar` tab in application settings before diagnostics.
- Added configurable page size and margins.
- Added configurable body typography, text size, line spacing, paragraph spacing, text color, link color, and separator color.
- Added configurable heading typography, size, color, and format for title levels 1 to 6.
- Stores the default export template as a simple ASCII JSON file that can be edited outside the app.

## Technical Notes

- Added backend export services for Markdown, PDF, and DOCX generation.
- Added typed frontend API wrappers and runtime save dialog helpers for desktop and browser contexts.
- Added export template normalization so unsupported font and style values fall back to safe defaults.
- Expanded export rendering for supported Markdown elements, including headings, paragraphs, blank lines, lists, task lists, tables, code blocks, blockquotes, rules, links, images, and inline formatting.
- Updated product architecture documentation and manual validation coverage for export behavior.
