# KnowNext.ai 1.0.1

## Summary

This release fixes first-run Android connectivity and ships the pending workspace interaction refinements for narrow layouts, Windows window controls, and document tabs. Windows continues to update through the signed Tauri `latest.json` manifest, and Android continues to update through the private APK `android-latest.json` manifest.

## Product Changes

- Android now searches the local network for a compatible KnowNext.ai mobile backend before asking the user for anything.
- The Android fallback screen uses product copy instead of API terminology and only asks for the computer address when automatic discovery fails.
- Android release builds can connect to local HTTP backends, while the client rejects non-local `http://` endpoints.
- Compact tab and prompt controls now switch at the `xs` breakpoint, with `2xs` available for the narrowest window checks.
- The Windows app window can be resized down to 360 px for the `2xs` layout.
- Double-clicking the Windows titlebar toggles maximize and restore.
- Closeable tabs now expose a right-click menu with close, close others, and close all actions.
- The release notes tab can be reordered with document tabs, and tab cursors use the default pointer style.

## Distribution

- Windows NSIS installer for manual installation.
- Windows MSI artifact for the signed Tauri updater.
- Signed Windows updater manifest `latest.json`.
- Signed Android arm64 APK for private installation.
- Android private updater manifest `android-latest.json`.

## Validation

- `pnpm release:check`
- Windows release workflow publishes `KnowNext.ai_1.0.1_x64-setup.exe`, `KnowNext.ai_1.0.1_x64_en-US.msi`, both `.sig` files, and `latest.json`.
- Android release workflow publishes `KnowNext.ai-android-arm64-v1.0.1.apk` and `android-latest.json`.
- Confirm `latest.json` resolves to `1.0.1` and points `windows-x86_64.url` to the MSI artifact.
- Confirm `android-latest.json` resolves to `1.0.1` and points to the Android arm64 APK.
