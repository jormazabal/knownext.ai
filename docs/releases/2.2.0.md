# KnowNext.ai 2.2.0

KnowNext.ai 2.2.0 is a diagramming and AI-documentation release focused on making Mermaid diagrams a professional, editable and exportable part of the Markdown workspace.

## What Changed

- Mermaid diagrams are now first-class document content. They render visually in the editor, remain stored as editable Markdown, and expose hover actions for editing or deleting the diagram.
- The Markdown toolbar includes diagram insertion next to image insertion, with a dedicated dialog for creating, validating and previewing Mermaid code before inserting it.
- The diagram editor now uses a three-column workflow: diagram type and controls on the left, a numbered Mermaid code editor in the center, and an independent visual preview on the right.
- Diagram examples are searchable through an enriched selector with categories for core, product, technical, data and beta diagram types.
- Diagram metadata supports optional captions and width presets so documents and exports can keep a professional layout.
- Diagram capability settings now control compatible, local visual and advanced profiles, including local Lucide icons, project-local image policy and Mermaid beta syntax policy.
- AI interactions can propose structured Mermaid diagram insertions when a diagram is a better representation than prose or tables.
- PDF and DOCX exports embed rendered diagram images instead of raw Mermaid code on desktop builds. Android keeps the lightweight PDF fallback while DOCX embedding remains available through the Rust document writer.
- Documentation and validation checklists were updated for Mermaid editing, AI diagram generation and export acceptance.

## Validation Required Before Publication

- `pnpm version:check`
- `pnpm release:check`
- Windows Tauri release build with updater signing configured
- Android release build with Android signing configured
- Manual Windows acceptance: update from 2.1.0 to 2.2.0, open the app, create or open a Markdown document, insert a Mermaid diagram, edit it, save, reopen and confirm app data is preserved.
- Manual Mermaid acceptance: insert stable examples, beta examples and local-icon examples under the active profile; confirm validation, preview, edit and delete flows work.
- Manual AI diagram acceptance: ask AI to create a process, sequence and architecture diagram; confirm the result is editable Mermaid and renders visually in the document.
- Manual export acceptance: export a document containing Mermaid diagrams to PDF and DOCX and confirm the exported files contain rendered diagram images.
- Manual Android smoke/update acceptance from 2.1.0 to 2.2.0, including offline operation without a workstation app or external product service running.
- GitHub release asset verification for MSI, NSIS, Windows signatures, `latest.json`, Android APK, and `android-latest.json`.

## Known Limitations

- Mermaid `architecture-beta` and other beta grammars are still sensitive to Mermaid upstream syntax changes. Use the dialog validation before inserting beta diagrams.
- Android PDF export uses the lightweight text fallback for Mermaid diagrams until the desktop PDF image pipeline has an Android-compatible renderer.
- AI diagram generation depends on the configured provider. Generated Mermaid should be validated in the editor before relying on it in final documents.
- GitHub remote synchronization still requires a valid GitHub account and repository permissions; when access is missing, remote sync remains paused while local history stays available.
- Agentic web research remains unavailable; local guided agentic limits are exposed but external web investigation is intentionally not active.
- Document previews and exports are Rust-managed and currently best-effort for formats that require complex conversion.

Do not publish this release if packaged Windows or Android builds fail, updater signing is unavailable, Android signing is unavailable, critical manual acceptance fails, or update manifests do not resolve to `2.2.0`.
