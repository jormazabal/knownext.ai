# KnowNext.ai 0.21.0

## Summary

This release improves the daily documentation workspace with persistent user notes, safer AI context handling, drag-and-drop file organization, and a more stable prompt input experience.

## Product Changes

- Added a pinned `Notas` tab next to IA.
- Keeps notes outside the project file tree.
- Autosaves notes without save, sync, history, export, or project document actions.
- Keeps IA and Notas pinned at the start of the tab strip while normal document tabs can scroll and reorder.
- Allows ordinary document tabs to be reordered with drag and drop.
- Allows moving project folders and files from the document tree with drag and drop.
- Allows dropping project documents and attachments from the tree into the prompt input as AI context.

## AI Editing And Context

- Treats AI-applied document changes as real local edits.
- Persists AI edits as recoverable drafts so refreshes do not silently lose generated content.
- Adds XLSX files to the supported AI context attachment flow.
- Removes context sources optimistically so deleted chips are no longer sent with the next prompt.
- Clarifies current-context behavior so the AI does not answer from old context sources in conversation history.
- Keeps selected text and attached context chips inside the prompt input shell.
- Prevents prompt context chips from changing the active document's visual position.

## Interface Refinements

- Added reusable circular countdown close buttons.
- Uses countdown close buttons in app notices and AI response bubbles.
- Adds smooth notice show/hide transitions.
- Updates notice styling with subtle tone backgrounds and plain representative icons.
- Removes the extra divider line under prompt context chips.

## Technical Notes

- Added typed notes state and backend notes persistence contracts.
- Added frontend helpers for active AI context source filtering.
- Added backend routes, schemas, and services for persistent notes.
- Extended AI context extraction and source resolution paths for workbook context.
- Added focused frontend and backend coverage for notes, tab reordering, context removal, drag-and-drop, countdown closes, and prompt context layout.
