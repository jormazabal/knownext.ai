# KnowNext.ai 2.0.4

KnowNext.ai 2.0.4 is a Windows stability release focused on silent local Git execution, calmer local-first synchronization, clearer Git/GitHub diagnostics, and a corrected AI document-creation flow.

## What Changed

- Git commands executed by the Rust runtime now run through a centralized helper.
- Windows Git subprocesses are hidden, so internal history and sync checks no longer open terminal windows.
- Git runs non-interactively with terminal prompts disabled, preventing credential prompts from leaking into normal app startup.
- Startup and background sync checks are less aggressive. External-change scans use a slower cadence and focus events, while GitHub-paused projects back off instead of retrying repeatedly.
- `auto-github` projects remain usable as local-first workspaces when GitHub is unauthenticated, offline, or unavailable.
- The settings runtime panel now shows a separate Git/GitHub diagnostic service with the active project, folder, local Git state, origin and remote-access state.
- AI requests are now persisted as conversation events, so prompts sent from a document are visible later in the IA tab.
- AI document creation now uses a structured Rust/Tauri contract: the model proposes `create_document`, Rust validates permissions, writes the Markdown document locally and returns the updated tree/document operation.
- The default assisted AI permission set now allows document creation while keeping destructive delete permissions disabled.

## Validation Required Before Publication

- `pnpm version:check`
- `pnpm release:check`
- Windows Tauri release build with updater signing configured
- Android release build with Android signing configured
- Manual Windows startup acceptance from 2.0.3 to 2.0.4: installed app opens without terminal windows repeatedly opening and closing.
- Manual Windows local-first acceptance on an `auto-github` project without GitHub login: documents remain editable, local Git remains available and GitHub is shown as paused.
- Manual AI acceptance: ask the assistant to create a Markdown document, verify that the new document appears in the tree, opens as a tab, and the prompt plus result are visible in the IA tab.
- Manual Android smoke/update acceptance from 2.0.3 to 2.0.4
- GitHub release asset verification for MSI, NSIS, Windows signatures, `latest.json`, Android APK, and `android-latest.json`

## Known Limitations

- GitHub remote synchronization still requires a valid GitHub account and repository permissions; when access is missing, remote sync remains paused while local history stays available.
- AI provider execution requires locally stored OpenAI credentials and still needs end-to-end validation with real keys before provider acceptance can be claimed.
- AI image generation, automatic semantic RAG/vector-store and agentic web research remain unavailable accepted capabilities in this release.
- Document previews and exports are Rust-managed and currently best-effort for formats that require complex conversion.

Do not publish this release if packaged Windows or Android builds fail, updater signing is unavailable, Android signing is unavailable, critical manual acceptance fails, or update manifests do not resolve to `2.0.4`.
