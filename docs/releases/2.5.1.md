# KnowNext.ai 2.5.1

KnowNext.ai 2.5.1 is a focused synchronization fix for projects that contain files with UTF-8 names, especially generated image assets with Spanish accents.

## What Changed

- Fixed Git quoted-path decoding in the Rust runtime so filenames with accented characters are reconstructed as UTF-8 instead of mojibake.
- The `Guardado y sincronizacion` drawer now receives correct names such as `Cronologia visual del Mazda MX-5.png`, `Guia de decision.png` and `Linea temporal...` when Git reports them as pending.
- Local history and GitHub pending-state comparisons now share the same path decoder, avoiding mismatches between filesystem paths and Git diff paths.
- Added focused Rust tests for Git path decoding and the file synchronization overview contract.

## Validation Required Before Publication

- `pnpm version:check`
- `pnpm release:check`
- Windows Tauri release build with updater signing configured
- Android release build with Android signing configured
- Manual sync acceptance: create or import files under `assets/generated` with accented names, open `Guardado y sincronizacion`, and confirm the displayed names are correct and can be added to local history.
- GitHub release asset verification for MSI, NSIS, Windows signatures, `latest.json`, Android APK and `android-latest.json`.

## Known Limitations

- GitHub synchronization still depends on account, repository permission and network availability; unavailable remotes pause automatic sync while local history remains usable.

Do not publish this release if packaged Windows or Android builds fail, updater signing is unavailable, Android signing is unavailable, critical manual acceptance fails, or update manifests do not resolve to `2.5.1`.
