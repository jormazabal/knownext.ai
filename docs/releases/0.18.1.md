# KnowNext.ai 0.18.1

## Summary

KnowNext.ai 0.18.1 refines the project-level protection, history, and synchronization experience so editors can understand what is happening without learning Git terminology.

## Product Changes

- Replaced the previous project-status entry with `Protección e historial`, placed next to project settings in the document tree.
- Moved the project-level backup/history review into a focused modal instead of a right-side panel tied to the active document.
- Added a clear summary tab explaining the current protection level, synchronization mode, situation, and recommended action.
- Split detailed information into `Cambios para guardar`, `Omitidos`, and `Detalles` tabs.
- Changed action labels from import-oriented wording to documentation-oriented wording: `Comprobar de nuevo`, `Guardar recomendados`, `Guardar seleccionados`, and `Aceptar omitidos`.

## Omitted Files

- Protected files such as `.env` remain non-selectable and are not saved to history or uploaded to GitHub.
- Users can accept expected omitted files so they stop generating alerts for the same detected review.
- Accepted omitted files remain visible in the modal for later consultation.

## Technical Notes

- Replaced the old document-header project sync indicator with a project-tree status model.
- Persisted accepted external-change review identifiers per project in local storage.
- Preserved backend-owned import/sync services while changing the frontend language to project protection and history.

## Validation

- `pnpm --filter @knownext/desktop build`
- `pnpm --filter @knownext/desktop test`
- Browser validation on `http://127.0.0.1:1420/` for the `Protección e historial` entry, modal tabs, accepted omitted file state, and removal of old import/status terminology.

## Distribution

The GitHub release for `v0.18.1` must include the NSIS installer, MSI installer, both updater signatures, and `latest.json`. The published `latest.json` must resolve to version `0.18.1` and keep `windows-x86_64.url` pointing to the MSI artifact.
