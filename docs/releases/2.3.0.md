# KnowNext.ai 2.3.0

KnowNext.ai 2.3.0 is an AI-skills and visual-document workflow release focused on making AI capabilities inspectable and making embedded images and diagrams behave like one professional document element.

## What Changed

- AI base skills are now bundled as compact Rust-governed capabilities with manifests, modes, validators, examples, diagnostics and read-only inspection from `Ajustes > Skills de IA`.
- The AI runtime now uses a hybrid skill-selection model. Rust prefilters candidates, validates the selector decision, composes only accepted skill instructions, and records skill/mode applications and diagnostics without trusting provider text.
- Mermaid capabilities are organized as modes inside `knownext.mermaid`, backed by a single Rust Mermaid catalog with diagram families, aliases, maturity levels, beta policy and validators.
- Markdown table generation can be selected as `knownext.markdown` table mode when the request and action are compatible.
- Document visual elements are now unified: embedded images and Mermaid diagrams share the same hover toolbar pattern for edit, reset size, fullscreen and delete.
- Embedded images and diagrams use document-local resizing instead of dialog sizing controls. Image resizing is live while dragging, proportional, responsive by default, and capped at the available document width so it cannot create empty white margins.
- Fullscreen inspection is available for embedded images and rendered Mermaid diagrams with zoom, fit, pan and keyboard close behavior.
- Diagram editing keeps content-focused controls in the dialog, while visual presentation stays in the document surface.

## Validation Required Before Publication

- `pnpm version:check`
- `pnpm release:check`
- Windows Tauri release build with updater signing configured
- Android release build with Android signing configured
- Manual Windows acceptance: update from 2.2.0 to 2.3.0, open the app, inspect `Ajustes > Skills de IA`, insert an image and a Mermaid diagram, resize both, reset both, open fullscreen and confirm app data is preserved.
- Manual image acceptance: insert or open existing images, confirm default responsive sizing, live proportional resize, max-width cap, reset-to-default behavior, fullscreen zoom/pan and delete.
- Manual diagram acceptance: insert Mermaid stable and beta examples, confirm visual rendering, common toolbar, vertical resize, reset, fullscreen rendering, edit and delete.
- Manual AI skills acceptance: use selection preview for Mermaid and Markdown table prompts, ask AI for a diagram and a Markdown table, and confirm `usedSkills`, `skillApplications` and diagnostics are generated by Rust.
- Manual Android smoke/update acceptance from 2.2.0 to 2.3.0, including offline operation without a workstation app or external product service running.
- GitHub release asset verification for MSI, NSIS, Windows signatures, `latest.json`, Android APK, and `android-latest.json`.

## Known Limitations

- User/imported skills are represented in contracts and passive UI copy, but creation, editing, import, export and project-level activation remain disabled in this release.
- Only Mermaid and Markdown table skills are active runtime capabilities in this release. Document review, compose, edit, project knowledge and governance remain visible base capabilities until their validators and application flows are complete.
- Mermaid `architecture-beta` and other beta grammars remain sensitive to Mermaid upstream syntax changes. Use validation before inserting beta diagrams.
- AI provider execution depends on locally configured credentials. Provider-backed skill selection and generation should be validated with a real key before relying on them for final documentation.
- Android PDF export uses the lightweight text fallback for Mermaid diagrams until the desktop PDF image pipeline has an Android-compatible renderer.
- GitHub remote synchronization still requires a valid GitHub account and repository permissions; when access is missing, remote sync remains paused while local history stays available.
- Agentic web research remains unavailable; local guided agentic limits are exposed but external web investigation is intentionally not active.
- Document previews and exports are Rust-managed and currently best-effort for formats that require complex conversion.

Do not publish this release if packaged Windows or Android builds fail, updater signing is unavailable, Android signing is unavailable, critical manual acceptance fails, or update manifests do not resolve to `2.3.0`.
