# KnowNext.ai 1.0.0

## Summary

This release promotes KnowNext.ai to a cross-platform installable product for Windows and private Android APK distribution. Windows keeps the signed Tauri updater flow, while Android adds a native private update channel that downloads a verified APK and hands installation to the Android system installer.

## Product Changes

- Added Android private APK update checks from `android-latest.json`.
- Added Android update progress inside the existing `Buscar actualizaciones` flow.
- Preserves Android app data across updates by requiring the same package id, same signing certificate, and increasing `versionCode`.
- Keeps the Android shell phone-native by hiding desktop titlebar controls and using mobile-specific spacing and touch sizing.
- Uses the same orange line-brain icon for Windows and Android application icons.
- Improves narrow-width document tabs, editor toolbar options, prompt input options, modals, and app menus.

## Android Private Update Channel

- Android release APKs are published as GitHub Release assets.
- `android-latest.json` declares the Android package id, semantic version, `versionCode`, supported ABI, SHA-256 digest, size, and APK URL.
- The APK updater rejects incompatible manifests, unsupported ABIs, non-HTTPS URLs, downgrades, wrong package ids, wrong `versionCode`, SHA-256 mismatches, and APKs signed by a different certificate.
- If Android blocks package installs from KnowNext.ai, the app opens the system settings screen and the user can retry the update after granting permission.

## Distribution

- Windows NSIS installer for manual installation.
- Windows MSI artifact for the signed Tauri updater.
- Signed Windows updater manifest `latest.json`.
- Signed Android arm64 APK for private installation.
- Android private updater manifest `android-latest.json`.

## Release Requirements

- Windows release signing requires `TAURI_SIGNING_PRIVATE_KEY` and `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`.
- Android private APK signing requires `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, and `ANDROID_KEY_PASSWORD`.
- Android `versionCode` is derived as `major * 1000000 + minor * 1000 + patch`; it is `1000000` for `1.0.0` and must only increase in future releases.

## Validation

- `pnpm release:check`
- Windows release workflow publishes NSIS, MSI, updater signatures, and `latest.json`.
- Android release workflow publishes `KnowNext.ai-android-arm64-v1.0.0.apk` and `android-latest.json`.
- Install an older Android APK, configure a backend endpoint, update to `1.0.0`, and confirm the saved endpoint remains configured.
