# KnowNext.ai 2.0.5

KnowNext.ai 2.0.5 is a functionality and UX release focused on making the local-first AI features operational and restoring important workspace interactions before rolling updates to Windows and Android devices.

## What Changed

- Added local RAG indexing through the Rust/Tauri runtime. Project documents and supported text attachments can be indexed locally, rebuilt, cleared, and used as contextual chunks in AI interactions.
- Added runtime-mediated image generation with OpenAI. Generated images are permission checked, saved as local project assets, indexed as image assets, and inserted into Markdown when configured.
- Added `gpt-image-2` as the default image generation model, with higher-resolution size options and image-model selector guidance using per-image pricing.
- Refined the app settings modal so the summary separates response, image generation, vision, and transcription models.
- Simplified settings diagnostics and capability panels to reduce technical copy and nested visual weight.
- Made export template settings autosave on every change; the Export tab no longer requires a manual save action.
- Restored key workspace interactions including document/folder moving, translucent drag feedback, prompt-context attachment flows, bounded `@` picker behavior, tab close actions, import/open behavior, generated image references, quote toggling, and local history updates after saves.

## Validation Required Before Publication

- `pnpm version:check`
- `pnpm release:check`
- Windows Tauri release build with updater signing configured
- Android release build with Android signing configured
- Manual Windows acceptance: update from 2.0.4 to 2.0.5, open the app, confirm settings save state, edit Export settings and confirm changes persist without pressing a save button.
- Manual workspace acceptance: move documents and folders by drag and drop, drag documents into the prompt context, reorder tabs, close all tabs, import a single supported document and confirm it opens.
- Manual AI acceptance: configure RAG, rebuild the local index, ask a contextual document question, generate an image with `gpt-image-2`, and confirm the Markdown reference renders.
- Manual Android smoke/update acceptance from 2.0.4 to 2.0.5, including offline operation without a workstation app or external product service running.
- GitHub release asset verification for MSI, NSIS, Windows signatures, `latest.json`, Android APK, and `android-latest.json`.

## Known Limitations

- GitHub remote synchronization still requires a valid GitHub account and repository permissions; when access is missing, remote sync remains paused while local history stays available.
- AI provider execution requires locally stored OpenAI credentials and should be manually accepted with real credentials on Windows before relying on provider workflows.
- Agentic web research remains unavailable; local guided agentic limits are exposed but external web investigation is intentionally not active.
- Document previews and exports are Rust-managed and currently best-effort for formats that require complex conversion.

Do not publish this release if packaged Windows or Android builds fail, updater signing is unavailable, Android signing is unavailable, critical manual acceptance fails, or update manifests do not resolve to `2.0.5`.
