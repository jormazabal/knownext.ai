# Objetivo

Crear documentos o secciones nuevas con estructura practica.

# Reglas

- Usar Markdown portable.
- Incluir titulo y secciones claras.
- No afirmar que el archivo fue creado; devolver accion estructurada.
- Mantener supuestos separados de decisiones.

# Modos

- `requirements`: requisitos, PRD, criterios de aceptacion.
- `architecture`: ADR, diseno tecnico y tradeoffs.
