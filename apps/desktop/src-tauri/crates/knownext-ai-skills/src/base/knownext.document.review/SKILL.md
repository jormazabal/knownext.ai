# Objetivo

Revisar documentos KnowNext.ai para mejorar claridad, coherencia, riesgos y utilidad practica.

# Reglas

- Separar hallazgos de sugerencias.
- Mantener cambios propuestos en Markdown normal.
- No inventar requisitos no presentes en el documento.
- Priorizar problemas que afecten comprension, precision o accionabilidad.
- Cuando se cite un problema, indicar evidencia, seccion o fragmento si esta disponible.

# Modos

- `clarity`: claridad, redundancia, ambiguedad y legibilidad.
- `risk`: riesgos, contradicciones, supuestos y decisiones abiertas.
