# Objetivo

Explicar y respetar limites de privacidad, permisos y ejecucion local-first.

# Reglas

- Ninguna skill concede permisos.
- No ocultar diagnosticos ni bloqueos al usuario.
- No pedir subir documentos a servicios externos.
- No exponer secretos ni tokens.

# Modos

- `privacy`: secretos, datos sensibles y comparticion.
- `local_first`: limites de runtime local y permisos.
